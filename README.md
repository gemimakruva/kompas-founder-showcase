# Kompas Founder

Founder DNA assessment platform. 48 questions, 512 unique profiles, one personalized report.

## What it does

Kompas Founder maps a founder's decision-making patterns across 7 dimensions and classifies them into one of 4 archetypes. The result is a detailed DNA profile with coaching recommendations specific to that founder's strengths and blind spots.

The assessment takes about 15 minutes. The output is a paid report (Rp 149k-249k) covering:

- **Founder archetype** (1 of 4 primary types)
- **Dimensional scores** across 7 areas
- **DNA profile** (1 of 512 unique combinations)
- **Personalized coaching** based on the profile's specific patterns

## The model

**4 Archetypes** form the primary classification. Each founder maps to one dominant type based on their decision patterns.

**7 Dimensions** measure distinct aspects of how a founder thinks, acts, and leads. Each dimension is scored independently.

**512 DNA Profiles** come from the combination of archetype and dimensional scores. No two profiles get the same coaching output.

## How Claude fits in

Claude handles the psychometric analysis layer: interpreting response patterns, generating profile narratives, and producing coaching recommendations. Each report is generated fresh based on that specific founder's answers, not pulled from a template library.

## Tech stack

- Laravel 12
- Filament 3 (admin panel)
- Livewire 3 (interactive UI)
- Claude API (analysis and report generation)
- PostgreSQL

## Revenue

Paid assessment reports. Each completed assessment generates a personalized PDF report at Rp 149,000-249,000 depending on the package.
